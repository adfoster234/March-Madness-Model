# March Madness Model

## Overview

This project uses R to build a logistic regression model for predicting NCAA March Madness game outcomes.

## Data

The model uses historical college basketball team performance data to evaluate factors that may be associated with winning games.

## Method

A logistic regression model was used to estimate the probability of a team winning based on team-level statistics.

## Tools

- R
- R Markdown
- Logistic Regression

## 2026 Results

The model was evaluated against the 2026 NCAA Tournament results. Of the model's top 10 ranked teams:

- 7 reached the Sweet 16
- 3 reached the Final Four
- 2 reached the National Championship
- 1 won the National Championship

Michigan was ranked among the model's top teams and ultimately won the 2026 NCAA Championship.
